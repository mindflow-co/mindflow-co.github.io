# Mindflow v0.6.1

**Released:** 2026-06-28

## What's new
- **Faster, more accurate English dictation.** Dictation in English now runs on a new on-device speech engine (NVIDIA Parakeet) that is both quicker and more accurate than before — noticeably better on technical terms like tool names, APIs, and code identifiers. It runs entirely on your Mac. You can turn it off in Settings → Dictation, in which case dictation uses Whisper as before.

## Fixes
- **The right speech model is now chosen for your language out of the box.** Picking Arabic now sets up the higher-accuracy multilingual model automatically instead of defaulting to the faster English-oriented one, so first-run accuracy for non-English languages is better without any manual model picking.

## Under the hood
- Whisper remains a built-in fallback for dictation: it's used for every language other than English, and for the first English dictations while the new engine finishes loading — so dictation keeps working without interruption.
- The new English dictation engine downloads once in the background (about 1 GB) the first time it's used; until it's ready, dictation falls back to Whisper automatically.
- Everything stays 100% on-device — no cloud, no new permissions.
