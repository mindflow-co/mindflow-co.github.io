# Mindflow v0.13.1

**Released:** 2026-08-25

## Fixes

- **Transcribing a file did nothing if your model was Arabic Pro.** Dropping a file in, using a watched folder, or asking your AI assistant to transcribe something would accept the job and then quietly produce nothing — no transcript, no error. Arabic Pro is a different kind of model from the ones file transcription uses, and it's the recommended default for Arabic, so this affected those users on every file, in either language. Mindflow now notices and transcribes with a suitable model instead, preferring one matched to the file's language.

- **You can now see what happened to a file you submitted.** Every file transcription records whether it was accepted, which model ran it, and whether it finished or failed — so a job can no longer disappear without explanation. Your AI assistant can read this too, and will tell you if something didn't work.

## Under the hood

- Diagnosing the above took an hour of reading code that couldn't be observed, then ten minutes once the record existed. It's written to a file rather than the system log, so tools and assistants can actually read it.
