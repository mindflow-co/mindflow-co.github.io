# Mindflow v0.7.16

**Released:** 2026-08-07

## What's new

- Arabic dictation now uses Arabic Pro automatically. Previously the dictation hotkey always went through Whisper, even for people whose meetings already used Arabic Pro — the dictation model was a single global setting with no per-language dimension. On real Arabic recordings the difference is large: roughly half the word error rate, and English technical terms come back as "authentication" and "OAuth" instead of being spelled out phonetically in Arabic script, which means you can actually search for them later. It applies to Arabic only, needs the Arabic Pro model downloaded, and falls back to Whisper automatically while the engine warms up. There is a new switch in Settings → Dictation if you would rather force the model you picked yourself.

## Fixes

- Arabic transcripts can no longer fill up with a single repeated character. A meeting could previously end up with a long stretch of stretched-out Arabic letters where a sentence should be, sometimes followed by text that was never spoken. The transcription engine now detects that it has started looping and cuts the segment there, so you get a short true sentence instead of a long invented one. This does not affect correct transcripts in any way — the existing accuracy tests produce byte-identical output.

## Under the hood

- The repetition problem turned out to be more interesting than it looked. The engine is fully deterministic — the same audio always produces the same text — but on short segments it sits close to a tipping point, and moving the segment boundary by as little as 25 milliseconds can flip the same audio between a perfect transcript and a loop. That rules out the obvious explanations (audio levels, segment length, a known upstream fix) and is why this release adds a guard that bounds the damage rather than a tuning change that would only have moved the odds around. The investigation and the three plausible-but-wrong diagnoses it produced are written up in the project's engineering notes so the next person does not repeat them.
- A full survey of Arabic speech recognition through the start of August confirmed that the model Mindflow already uses remains the best available option for Arabic, including for mixed Arabic-English speech. Nothing newer displaced it.
