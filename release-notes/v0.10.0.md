# Mindflow v0.10.0

**Released:** 2026-08-20

## Mindflow now updates itself

New versions install on their own and Mindflow reopens — no banner to notice, no button to press.
This is the last release you will need to install by hand.

**It will never do this in the middle of something.** An update replaces the app and restarts it,
so Mindflow waits until nothing is in flight before touching anything. It holds off while:

- a meeting is being recorded, or is still being written up after you stop
- speaker identification is rewriting a transcript
- you are dictating and the text has not landed in your document yet
- a file or URL in the batch queue is still being transcribed

If it finds an update while you are busy, it simply waits and tries again later, checking about once
an hour. A recording is never interrupted, and nothing is ever half-installed.

You can switch it off in **Settings → About → "Install updates automatically"**, which returns to the
old behaviour of telling you an update is ready and letting you choose the moment.

## Note for this release only

Automatic updating is part of the app, so it starts working from this version onwards — v0.10.0
itself still needs the usual one click from the update banner. Every release after this one arrives
on its own.
