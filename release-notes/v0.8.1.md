# Mindflow v0.8.1

**Released:** 2026-08-20

## Fixes

- Fixed Mindflow telling you that System Audio Recording was switched off when it was switched on
  and working perfectly. If you updated to v0.8.0, granted the permission, and the Permissions
  screen still insisted it was missing — that was this bug, not your Mac. Re-adding the permission
  never helped because there was nothing wrong with it.

  The check tried to be clever: it listened for two seconds, and if another app claimed to be
  playing audio while Mindflow heard nothing, it concluded the permission must be blocked. But macOS
  reports an app as "playing audio" whenever it holds the sound device open, even when it is sitting
  in silence — so a single idle app in the background was enough to trigger a false alarm.

  Mindflow now only reports the permission as confirmed when it has actually heard something, and
  says so honestly the rest of the time instead of guessing. If you were affected, the warning
  clears itself as soon as your next meeting has audio in it — no action needed.
