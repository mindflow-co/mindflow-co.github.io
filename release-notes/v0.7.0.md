# Mindflow v0.7.0

**Released:** 2026-07-06

The biggest Mindflow update yet: your meetings now summarize themselves, name themselves, and transcribe faster — all 100% on your Mac.

## What's new
- **Meeting Notes.** Mindflow now writes a structured summary of every meeting entirely on your device — a Summary, Key Decisions, an Action Items table, and Discussion Highlights — shown side-by-side with the transcript. It runs on a local AI model, so nothing ever leaves your Mac.
- **Automatic meeting titles.** Instead of naming a meeting after the first thing said, Mindflow asks the local model for a short, descriptive title. There's also a "Rename with AI" button to re-title any past meeting.
- **A Home window.** Mindflow now opens a dashboard when you launch it — recent meetings, quick actions (record, dictate, transcribe a file or URL), live status, and search, all in one place. First launch walks you through setup. You can switch your model and language right from here.
- **Faster, more accurate English transcription.** Meetings in English now use the Parakeet speech engine for higher accuracy at greater speed. Other languages continue to use Whisper automatically.
- **Summaries for your AI assistant.** If you use Mindflow with Claude Code or another assistant, it can now generate and read meeting summaries directly through new tools.
- **Cleaner interface.** A refreshed design system across the app, a full-width Start Recording button when a meeting is detected, an actionable Batch Queue, real download progress (size, speed, percentage) when fetching models, and clearer permission screens.

> Meeting Notes and automatic titles use a local model via **Ollama** (free). Install Ollama and pull a model (e.g. `ollama pull qwen2.5:3b`) to enable them. Everything else works without it.

## Fixes
- Closing the Home window no longer quits Mindflow — it stays running in your menu bar as it should.
- More accurate speaker separation on multi-person calls.
- A range of reliability fixes to recording, dictation, model selection, and transcript saving that prevent problems from failing silently.

## Under the hood
- On-device summarization via Ollama (with llama.cpp as an alternative) — no cloud, no cost, no telemetry.
- Numerous correctness and safety improvements from a full internal code review.
