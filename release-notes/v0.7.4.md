# Mindflow v0.7.4

**Released:** 2026-07-10

A quality-of-life release for the recording hotkey — easier to press, honest about what it is, and safe from accidental triggers.

## What's new
- **New recording hotkey: ⌃⌥R** (Control + Option + R). Press once to start recording, again to stop — from anywhere on your Mac. The old default (Control + Option + Command + R) worked but needed three modifiers; the new one matches the dictation hotkey's style (⌃⌥Space) and is much more comfortable. If you're on an older default, Mindflow moves you to the new one automatically — and if you've set your own custom hotkey, it is left untouched. Rebind anytime in Settings → Shortcuts.
- The Start Recording button in the menu bar now shows **your actual configured hotkey** instead of a fixed hint, so what you see is always what works.

## Fixes
- Fixed recordings that could start when you pressed **⌘⇧R** — the browser hard-refresh shortcut. A hidden leftover binding kept that key combination able to trigger recording, and people upgrading from older versions could still have it as their active hotkey. Both paths are gone: the leftover was removed, and anyone still carrying the old binding is moved to the safe default automatically.

## Under the hood
- Hotkey defaults are now migrated generationally: when a default is retired, existing installs that never customized it follow along, while deliberate custom bindings are never overridden.
