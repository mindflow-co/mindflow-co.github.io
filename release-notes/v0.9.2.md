# Mindflow v0.9.2

**Released:** 2026-08-20

## You may need to download this one by hand — once

The app download has moved to GitHub Releases. Versions up to v0.9.1 had the old
download address built into them, so they cannot fetch this update on their own. Grab v0.9.2 from
the download button on the site (or from Releases) and install it over the top the usual way —
your transcripts, settings and permissions are untouched.

Automatic updates work normally again from v0.9.2 onwards, and this is a one-time interruption.

## Why the move

Every release used to publish the installer into the same repository that serves the website. Git
keeps a permanent copy of every version of every file, so 31 releases meant 31 copies of a ~77 MB
installer living in the site's history forever — around 2.3 GB of dead weight.

That had a visible cost: publishing a release had slowed to over thirteen minutes, and the site was
slow to pick up new versions. Installers now live in GitHub Releases, which is built for exactly
this and keeps them out of the site's history. Publishing now takes about ninety seconds.

Nothing about the app itself changed in this release, and nothing about your data or your privacy
changes: the app is still fully on-device.

## Under the hood

- `VERSION.json` now carries the exact download URL for each version, so the update metadata and the
  installer it describes can never drift apart.
- The site's history was rewritten to remove the old installer copies, taking the repository from
  713 MB to a little over 1 MB.
