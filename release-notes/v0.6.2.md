# Mindflow v0.6.2

**Released:** 2026-06-30

## What's new
- **The dictation speech engine now sets itself up upfront, with a progress bar.** The English dictation engine (NVIDIA Parakeet, ~500 MB) now downloads when you first set up Mindflow — or, on update, the next time you open the app — with a visible progress indicator in **Settings → Dictation** and a line in the menu-bar popover. Previously it downloaded silently the first time you dictated; now it's ready before you need it, and you can see and control it (Download / Retry) from Settings.

## Under the hood
- The download only runs when English dictation is enabled (the default). Turn dictation off, or set a non-English dictation language, and it's skipped.
- Dictation still falls back to Whisper automatically while the engine is downloading, so nothing is ever blocked.
- Everything stays 100% on-device — no cloud, no new permissions.
