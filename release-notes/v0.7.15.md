# Mindflow v0.7.15

**Released:** 2026-07-31

## Fixes

- Starting a recording is now much faster after the first one. Before beginning a recording, Mindflow runs a quick check that the speech engine accepts its settings — a safeguard that catches the kind of breakage where an updated speech engine silently stops producing any text at all. That check was being repeated in full on *every* start, loading the entire speech model each time, and it was costing roughly a second of the delay you saw before recording began. The result is now remembered for as long as Mindflow is running, so only the first recording after launch pays for it.

  The check still runs again whenever anything it depends on changes — a different language or model, an edited dictionary, an updated speech engine, or a model file that was replaced on disk — so the safeguard is fully intact. Mindflow simply stops re-asking a question it already has the answer to.

- The "Starting…" message no longer claims only the first start after launch is slow. Every start was slow; that is what this release fixes.

## Under the hood

- If two recordings are somehow started at the same instant, they now share a single engine check instead of running one after the other.
